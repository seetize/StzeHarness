# StzeHarness

Русскоязычная агентная фабрика: один Лид управляет небольшой командой специализированных агентов, а человек подключается только к действительно важным решениям.

Проект создан по мотивам архитектуры **Tiny Software Factory** из видео IndyDevDan «Fable 5.2 is CRACKED but THIS goes BEYOND THE MODEL». Это самостоятельная открытая реализация идеи, а не копия закрытого продукта.

## Что уже работает

- четыре агента: Лид, Архитектор, Инженер и Ревьюер;
- отдельные «четыре ядра» каждого агента: контекст, модель, промпт и инструменты;
- декомпозиция цели в командный поток задач;
- канбан со статусами и владельцами;
- общая комната агентов и социальный контракт общения;
- очередь решений человека с одобрением и отклонением;
- журнал активности и сохранение состояния в `data/state.json`;
- полностью русскоязычный адаптивный интерфейс;
- симулятор для работы без моделей;
- готовый адаптер для любого OpenAI-совместимого API: Ollama, vLLM, LM Studio или собственного шлюза.

## Быстрый запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173).

Продакшен-режим:

```bash
npm run build
npm start
```

Приложение будет доступно на [http://localhost:4310](http://localhost:4310).

## Подключение своей модели

По умолчанию используется безопасный детерминированный симулятор. Для OpenAI-совместимого API задайте переменные окружения:

```env
MODEL_PROVIDER=openai-compatible
MODEL_BASE_URL=http://localhost:11434/v1
MODEL_API_KEY=
MODEL_NAME=qwen3-coder
```

На Windows PowerShell:

```powershell
$env:MODEL_PROVIDER='openai-compatible'
$env:MODEL_BASE_URL='http://localhost:11434/v1'
$env:MODEL_NAME='qwen3-coder'
npm start
```

Ключ остаётся только на сервере. Браузер его не получает и не хранит.

## Как устроен цикл

```text
Цель человека
      ↓
Лид: декомпозиция и назначение владельцев
      ↓
Архитектор → Инженер → Ревьюер
      ↓
Развилка с ответственностью человека?
      ├─ нет → команда продолжает
      └─ да  → очередь решений → одобрить / отклонить
```

В симуляционном режиме этот маршрут создаётся локально и позволяет проверить весь интерфейс без расходов. В live-режиме специализированные ответы берутся через `/chat/completions`, а промпт каждого агента собирается из его собственного ядра.

## Структура

```text
src/                    React-интерфейс и общие типы
server/index.ts         HTTP API и раздача собранного клиента
server/store.ts         локальное сохранение состояния
server/orchestrator.ts  командный цикл и human-near-the-loop
server/model.ts         OpenAI-совместимый адаптер моделей
docs/VIDEO_ANALYSIS.md  разбор исходного видео и границы MVP
```

## Безопасность и ограничения MVP

- инструменты агентов сейчас описываются в профиле, но не запускают произвольные команды;
- нет многопользовательской авторизации и разграничения проектов;
- live-режим выполняет по одному запросу для каждого специалиста, без фоновой очереди;
- перед использованием в производстве добавьте изоляцию инструментов, секрет-хранилище, лимиты бюджета и аудит действий.
